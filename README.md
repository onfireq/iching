# 观易 · 易经研习

一个用于学习、深入了解并洞察《易经》的静态网页。零依赖、可离线运行，可直接部署到 GitHub Pages 等任意静态托管。

## 功能

| 页面 | 说明 |
|------|------|
| 首页 | 太极主题页，学习路径导览 |
| 六十四卦 | 64 卦全文：卦辞、彖传、大象、爻辞、小象（通行本），支持搜索、上经/下经筛选、卦画显示 |
| 卦详情 | 逐卦详解：卦画、卦德、上下卦、六爻爻位程序化分析（当位/中正/承乘比应/三才）、错综卦互参、卦序导航 |
| 起卦 | 铜钱法（含投掷动画）与数字法，自动推演本卦、动爻、变卦并给出经文依据 |
| 入门研习 | 10 篇专题文章：易之源流、太极阴阳、八卦、卦序、五行、河图洛书、占筮原理、十翼导读、现代启示 |
| 名词速查 | 60+ 易学术语分类速查：基本概念、卦爻关系、占筮术数、易学人物 |
| 白话讲易 | B 站《通俗易懂讲易经》合集 38 期视频卡片，逐卦白话讲解，卡片含卦画/封面/时长/播放量，点击直达 B 站 |

## 技术栈

- 纯 HTML + CSS + JavaScript（ES6），无任何外部依赖
- 单页应用（hash 路由），数据驱动渲染
- 深色 / 宣纸色双主题，玻璃拟态设计（延续 portfolio-next 设计语言）

## 文件结构

```
iching/
├── index.html    # 页面骨架
├── style.css     # 全部样式（双主题）
├── data.js       # 六十四卦全文数据（卦辞/彖/象/爻辞/小象）+ 八卦数据 + 卦德简注
├── bili.js       # B 站《通俗易懂讲易经》合集数据（38 期，含卦序关联，可重新抓取生成）
└── app.js        # 应用逻辑（路由/渲染/爻位分析/起卦引擎/文章/名词库/视频页）
```

## 本地运行

任意静态服务器即可：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 http://localhost:8000

## 部署到 GitHub Pages

1. 新建仓库 `iching`（或任意名）
2. 将本目录四个文件推送到仓库
3. 仓库 Settings → Pages → 选择 `main` 分支 / root 目录
4. 访问 `https://<用户名>.github.io/<仓库名>/`
